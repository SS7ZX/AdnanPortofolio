01 / Summary

My background combines hands-on MERN stack development with applied web security, specifically the OWASP Top 10, insecure direct object reference (IDOR) bugs, and authentication bypass patterns, grounded in a formal network engineering certification and one independently designed payment system.

I treat "developer" and "security tester" as one discipline rather than two, not as a marketing angle but as the habit that has caught the most bugs in my own code.

When I build a feature, I follow it with an attempt to break it: checking authentication flows for bypasses, testing forms for injection, checking endpoints for IDOR. That habit developed while building C-Pay, where being responsible for transaction logic meant "resists misuse" had to be the actual target from day one, not an afterthought.

I am early in my career and say so directly rather than inflating it. What I bring instead is consistency: every project referenced on this site was finished, documented, and in most cases pushed past the original scope.

02 / How I Work

Five working principles that show up across every project, not slogans picked for a portfolio.

  • Build FirstA working prototype with rough edges beats a perfect plan that never ships. Most of my learning has come from finishing things and then fixing what broke.
  • Test Like An OutsiderOnce a feature works, the next question is always how someone would abuse it. That single habit has caught more bugs than any external review, because it happens earlier and more often.
  • Document While BuildingNotes get written during development, not reconstructed afterward. That matters for handoffs and for anyone reviewing the work later, including future me.
  • Prefer Boring SolutionsAuditable beats clever. In C-Pay, transaction logic is deliberately isolated into a single code path, at some cost to flexibility, in exchange for confidence that balances cannot drift silently.
  • Name The GapsGo, Supabase Edge Functions, and formal bug bounty methodology are things I am actively learning, not things I have mastered, and I would rather flag that clearly than let it surface awkwardly later.
